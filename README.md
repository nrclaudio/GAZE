# GAZE

**Graph Attention for Zero-shot metabolite Estimation**

GAZE is a physics-informed graph neural network that predicts metabolite concentrations from gene expression data. Unlike conventional methods, GAZE can predict concentrations for metabolites that were never seen during training by leveraging metabolic network topology and chemical structure embeddings.

The model operates on a bipartite metabolic graph (5,414 nodes, 16,307 edges) where reaction nodes carry enzyme expression and metabolite nodes carry SMILES-derived structural embeddings. A Metabolite-Conditioned Reader (MCR) uses each metabolite's chemical structure as a query into learned pathway representations, producing predictions through shared weights with no metabolite-specific parameters.

Pretrained weights are included (trained on 867 cancer cell lines from the [CAMP](https://doi.org/10.1038/s41467-023-40217-2) dataset).

## Quick start

```python
from gaze import GAZEModel

model = GAZEModel.from_checkpoint(
    "weights/best_model.pt",
    graph_path="path/to/merged_metabolic_network.pt",
    gene_mapping_path="path/to/gene_mapping.json",
)

# gene_expression: [num_samples, num_genes] tensor
predictions = model.predict(gene_expression)
```

The metabolic graph (`merged_metabolic_network.pt`) and gene mapping (`gene_mapping.json`) are generated by the preprocessing scripts in the [reproducibility repository](https://github.com/nrclaudio/gaze-reproducibility).

## Architecture

GAZE combines five components in a unified forward pass:

1. **Relational bipartite convolutions** -- GATv2 attention over separate reaction-to-metabolite and metabolite-to-reaction edges, with residual connections and LayerNorm.

2. **Bidirectional cross-modal attention** -- aligns reaction and metabolite representations before and after each GNN layer.

3. **Metabolite-Conditioned Reader (MCR)** -- at readout, each metabolite's ChemBERTa SMILES embedding queries the contextualized reaction embeddings of its graph neighbors via scaled dot-product attention. This is what enables zero-shot prediction: the reader has no metabolite-specific parameters.

4. **Flux messages** -- predicted reaction fluxes modulate information propagation through the graph.

5. **Mass balance projection** -- a Cholesky-based projector enforces stoichiometric constraints on predicted fluxes during training.
